# neomax-policies

NeoMax 앱들의 개인정보처리방침을 **한 저장소에서** 호스팅한다.
앱마다 저장소를 따로 만들면 개수만큼 늘어나고, Pages 설정도 매번 다시 해야 한다.

```
neomax-policies/
├── index.html          앱 목록
├── harukan/index.html  하루칸
└── (앱 추가 시 폴더만 하나 더)
```

## 처음 한 번만 하는 설정

저장소 이름을 무엇으로 하느냐에 따라 주소가 달라진다. **둘 중 하나를 고른다.**

### ① 사용자 사이트 — 주소가 가장 짧다 (권장)

저장소 이름을 **`devk770319-ui.github.io`** 로 만든다.

```
https://devk770319-ui.github.io/harukan/
```

- 가장 짧고 깔끔하다. 나중에 앱 소개 페이지를 붙이기도 좋다.
- 단, 이 이름은 계정당 하나뿐이라 루트를 이 용도로 쓰게 된다.

### ② 일반 저장소 — 루트를 비워둔다

저장소 이름을 **`neomax-policies`** 로 만든다.

```
https://devk770319-ui.github.io/neomax-policies/harukan/
```

- 주소에 한 칸이 더 붙지만 루트는 자유롭게 남는다.

### 공통

1. GitHub 에서 **Public** 으로 저장소를 만든다.
2. 이 폴더 내용을 통째로 올린다.
3. **Settings → Pages** 에서
   - Source: `Deploy from a branch`
   - Branch: `main` / 폴더 `/ (root)`
4. 몇 분 뒤 주소가 열린다.

```bash
gh repo create devk770319-ui.github.io --public --source=. --push
```

## 새 앱을 추가할 때

저장소를 새로 만들 필요가 없다. **폴더 하나만 더 만든다.**

1. `앱이름/index.html` 로 방침 파일을 넣는다.
2. 루트 `index.html` 에 카드 블록 하나를 복사해 붙이고 폴더 이름만 바꾼다.
3. 커밋하고 밀면 몇 분 뒤 반영된다.

Play Console 에 넣을 주소는 `.../앱이름/` 이다.

## 트럭러시는 어떻게 하나

지금 트럭러시는 **이미 출시된 앱**이고 Play Console 에 아래 주소가 등록돼 있다.

```
https://devk770319-ui.github.io/truckrush-privacy/
```

**서두르지 않는 것을 권한다.** 살아 있는 앱의 방침 주소를 먼저 깨뜨릴 이유가 없다.

옮기고 싶다면 순서는 이렇다.

1. 이 저장소에 `truckrush/index.html` 을 만들고 기존 내용을 옮긴다.
2. 새 주소가 열리는지 확인한다.
3. Play Console 스토어 등록정보의 방침 URL 을 새 주소로 바꾼다.
4. **옛 저장소는 지우지 말고** `index.html` 을 아래 한 줄짜리 안내로 바꿔둔다.
   이미 퍼진 링크가 죽지 않는다.

```html
<meta http-equiv="refresh" content="0; url=https://devk770319-ui.github.io/harukan/">
```

## 게시 전 확인

- **시크릿 창으로 열어볼 것.** 로그인이 필요한 페이지는 Play 심사가 거절한다.
- 각 방침이 그 앱의 실제 동작과 맞는지. 아래가 바뀌면 방침도 같이 고친다.
  - 광고 종류·위치, 분석·오류수집 도구 추가, 서버 통신 추가, 권한 증감, 인앱 상품 변경

## 하루칸 방침이 지금 말하고 있는 것

앱 코드를 직접 확인해 쓴 내용이다. 2026-09-10 기준.

| 항목 | 상태 |
|---|---|
| 개발자 서버 | 없음 (`fetch`/XHR 0건) |
| 분석·크래시 도구 | 없음 |
| 회원가입·로그인 | 없음 |
