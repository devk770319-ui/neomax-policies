i케어 개인정보 처리방침

시행일: 2026년 9월 19일 · 버전 1.0 · 앱 패키지 com.neomax.icare

i케어(이하 "앱")는 발달이 느린 아이를 키우는 보호자가 치료 일정, 치료 기록, 영수증과 서류를 정리하고 보험 청구 서류를 묶는 데 쓰는 안드로이드 앱입니다. 에이치제이솔루션(이하 "운영자")는 개인정보보호법 제30조에 따라 앱이 어떤 정보를 어디에 저장하고, 무엇을 서버로 보내며, 어떻게 지우는지를 아래와 같이 알립니다.

가장 중요한 것 세 가지

  • 아이의 진단명, 치료 기록, 서류 사진은 기본적으로 사용자의 기기에만 저장됩니다. 서버로 가지 않습니다.
  • 사용자가 가족 공유를 직접 켠 경우에만 일부 정보가 서버에 저장되며, 그때도 진단명과 서류 파일은 운영자가 읽을 수 없도록 기기에서 암호화된 뒤 올라갑니다.
  • 앱은 광고를 싣지 않고, 광고 식별자와 위치 정보를 수집하지 않으며, 수집한 정보를 광고나 분석 목적으로 제3자에게 제공하지 않습니다.

1. 앱을 쓰는 두 가지 방식

앱은 로그인 없이 쓸 수 있습니다. 어떤 방식을 쓰느냐에 따라 정보가 머무는 곳이 다릅니다.

2.3 수집하지 않는 것

  • 광고 식별자(ADID), 기기 고유 번호
  • 앱 사용 행태 분석 데이터, 오류 자동 보고(크래시 리포트)
  • 보호자 본인의 이름·생년월일 (앱은 보호자의 신상 정보를 입력받지 않습니다)
  • 사진 보관함 전체 — 앱은 사용자가 고른 사진 한 장만 받으며, 보관함 접근 권한을 요구하지 않습니다

3. 기기에 저장되는 방식

  • 기록은 기기 안의 암호화된 데이터베이스에, 서류 사진은 암호화된 파일로 저장됩니다. 암호화 키는 기기의 보안 저장소(Android Keystore)에 있어 기기를 떠나지 않습니다.
  • 안드로이드의 자동 클라우드 백업과 기기 간 자동 이전에서 앱 데이터를 제외합니다. 다른 기기로 옮기려면 사용자가 설정에서 직접 비밀번호를 걸어 백업 파일을 만들어야 합니다.
  • 앱을 삭제하면 기기의 모든 앱 데이터가 함께 삭제됩니다.

4. 서버로 보내는 정보 — 가족 공유를 켠 경우에만

가족 공유는 사용자가 설정에서 직접 켜야 하며, 켤 때 별도 동의 화면을 거칩니다. 켜지 않으면 아래 내용은 해당하지 않습니다.

  • 서버로 가는 것: 아이 정보, 센터·담당자, 일정, 회차 기록, 서류의 종류·날짜·금액·상태, 서류 파일.
  • 운영자가 읽을 수 없는 것: 진단명과 서류 파일은 가족 구성원만 가진 키로 기기에서 암호화된 뒤 올라갑니다. 운영자의 서버에는 암호화된 형태로만 있습니다.
  • 서버로 가지 않는 것: 서류에서 읽어 낸 글자(OCR 텍스트), 아이의 얼굴이나 생활 사진.
  • 서버에서는 같은 가족의 구성원만 해당 가족의 데이터에 접근할 수 있도록 행 단위 접근 제어를 적용합니다.

5. 자동 채움(AI) 처리

서류 사진을 찍거나 다른 앱에서 글을 공유하면, 앱이 금액·날짜·서류 종류를 미리 채워 줍니다. 이때 다음 원칙을 지킵니다.

  • 사진은 기기 안에서 글자로 바뀝니다(온디바이스 문자 인식). 사진 자체는 서버로 가지 않습니다.
  • 서버로 보내기 전에 아이 이름은 [아이], 보호자 이름은 [보호자]로 바꾸고, 주민등록번호·전화번호·카드번호·이메일·계좌번호 형태의 문자열을 가립니다.
  • 가려진 글자만 인공지능 언어 모델에 전달되어 구조화된 값(금액, 날짜, 종류)으로 돌아옵니다.
  • 운영자 서버는 요청 본문과 응답 본문을 저장하지 않습니다. 요청 번호, 걸린 시간, 글자 수, 성공 여부만 남깁니다.
  • 채워진 값은 저장 전에 사용자가 확인하고 고칩니다. 자동 채움이 실패해도 직접 입력으로 저장할 수 있습니다.
  • 앱은 의료 조언이나 발달 판단을 하지 않으며, 인공지능에게도 그런 답을 요구하지 않습니다.

8. 사용자의 권리

  • 열람·정정: 모든 기록은 앱 안에서 직접 보고 고칠 수 있습니다.
  • 내보내기: 설정 → 내보내기로 전체 기록(CSV)과 서류(ZIP)를 받을 수 있습니다. 무료·유료와 관계없이 항상 제공됩니다.
  • 삭제: 설정 → 전체 삭제. 계정 모드에서는 계정 삭제.
  • 동의 철회: 진단명 동의는 진단명을 지우는 것으로, 가족 공유 동의는 공유를 끄는 것으로 철회됩니다. 철회해도 나머지 기능은 그대로 쓸 수 있습니다.

권리 행사는 앱 안에서 직접 하거나 10항의 연락처로 요청할 수 있습니다. 요청은 10일 이내에 처리합니다.

9. 아동의 개인정보

  • 이 앱은 보호자(성인)가 쓰는 앱이며, 아동을 사용자로 두지 않습니다.
  • 만 14세 미만 아동의 정보는 법정대리인인 보호자가 입력하는 것으로만 들어옵니다. 진단명을 입력할 때 법정대리인임을 확인하는 동의를 따로 받습니다.
  • 아동의 정보는 오직 그 아동의 기록을 정리하는 목적으로만 쓰이며, 어떤 형태의 평가·프로파일링·광고에도 쓰이지 않습니다.

11. 안전 조치

  • 기기: 데이터베이스와 파일 암호화, Android Keystore 키 관리, 자동 백업 제외, 문서 화면 스크린샷 제한.
  • 서버: HTTPS 전송, 가족 단위 행 접근 제어, 진단명·서류 파일의 기기 측 암호화, 인공지능 요청·응답 본문 미저장.
  • 운영: 서버 관리 키를 앱에 넣지 않으며, 로그와 오류 기록에 개인정보나 서류 내용을 남기지 않도록 빌드 단계에서 검사합니다.
